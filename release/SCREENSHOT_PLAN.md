# Truthful store screenshot plan

Capture these only from the release build with representative demo data. Do not use mock screens that differ from the submitted product.

## Android Play listing

Export portrait PNG/JPEG images at 1080 × 1920 or higher:

1. Today — All devices with summed time and active digital span.
2. Apps — category filters and a configured limit.
3. Trends — All/Android/Chrome selector and 7-day chart.
4. Connected devices — Android and a paired Chrome installation.
5. Limit setup — strict versus soft blocking choice.

## Chrome Web Store

Export five 1280 × 800 PNG/JPEG images:

1. First-run QR connection page.
2. Today — All devices and active digital span.
3. Website/source list with category and limit controls.
4. Cross-platform Trends view.
5. Settings — local-first sync state and category budgets.

Before capture, remove personal email, real device names, private domains, tokens, QR secrets, and actual usage history. Use a dedicated demo account. Save final files under `release/screenshots/android/` and `release/screenshots/chrome/`.
