# Archived optional store listing copy

SyncOn is currently a personal-use project and is not being submitted to either store. This copy is retained only as a future reference.

## Google Play

**App name:** SyncOn — Screen Time & Focus

**Short description (80 characters max):** Local-first screen time, calm limits, and optional Chrome sync.

**Full description:**

SyncOn helps you understand and shape your digital time without turning your wellbeing into an ad profile.

Track Android apps on a human 4 AM–4 AM day, set strict or flexible limits, receive calm warnings, review categories and long-term trends, and keep tracking through reboots or aggressive background restrictions.

Install the optional Chrome companion and connect it by scanning a short-lived QR code. SyncOn then shows Android, Chrome, and combined time—including overlap-adjusted active digital span—while each device continues tracking and enforcing its own limits offline.

Key features:
- Precise foreground app and focused-domain tracking
- All / Android / Chrome dashboards and trends
- Strict blocks or soft snoozes
- App, website, and shared category budgets
- 4 AM usage-day boundary
- Three-year local history and JSON export/import
- Local-first behavior with optional encrypted account sync
- Connected-device revocation and cloud account deletion
- No ads, no page-content collection, and no cross-site tracking

Android requires Usage Access for app timing and Accessibility for immediate limit enforcement. These permissions are explained during onboarding and are used only for SyncOn's visible tracking and blocking features.

## Chrome Web Store

**Name:** SyncOn — Browser Screen Time

**Summary:** Private focused website tracking and limits connected securely to SyncOn Android.

**Description:**

SyncOn records time only while a normal web page is focused and the computer is active. See today's top websites, categories, 7/14/30-day trends, and overlap-adjusted time across Chrome and a paired Android phone.

Create per-site or category budgets, choose strict blocking or a short snooze, and receive a native warning before time runs out. Tracking, blocking, history, and settings remain usable offline.

Pairing is required. On first install, SyncOn displays a single-use QR code that the Android app scans to activate the browser and grant it access to the same account. The QR contains no password or usage history.

SyncOn stores normalized domains—not page paths, searches, page contents, form data, or keystrokes. It includes no advertising, third-party analytics, or remote code.
